There are two types of people#

There are two types of people using Hermes right now: people who are chatting with it and people who are running it 0:00. From the outside, they look pretty much identical: same install, same dashboard, same first message 0:04. One type keeps describing what they want, while the other builds one agent, goes to sleep, and the work is already being done 0:18.

Hermes ships with over 60 built-in tools and a stack of settings, and most people do not set any of them 0:47. The difference between building and running an agent comes down to configuring those tools and settings rather than only chatting with the default setup 0:47.

The foundation is where the agent runs. Most Hermes tutorials start on the desktop app, and it is fine to learn on, but the moment you close your laptop, the agent dies with it 1:34. Here's the setting that most people#

Auxiliary tasks

  • Auxiliary tasks are background jobs that run constantly, such as compressing conversations, reading web pages, and summarizing documents 5:00.
  • Set auxiliary tasks to auto 5:03.
  • When set to auto, these tasks hand off to lighter models automatically 5:09.
  • This keeps the main model fast and focused on the actual work 5:14.

Mixture of agents

  • Mixture of agents uses multiple models to answer the same prompt 5:21.
  • One model then fuses the best version together 5:26.
  • This is slower, but can make a massive difference on genuinely hard problems 5:26.
  • One setting decides whether the agent moves fast or thinks deeply 5:33.

Soul MD

  • There is a file called Soul MD that sits in the very first slot of everything Hermes reads before it responds 5:51.
  • Soul MD is not memory; it is identity 5:58.
  • It defines who the agent is, not what it knows 5:58.
  • With no Soul MD configured, the response can be accurate but generic 6:15.
  • After writing tone, formatting rules, and preferences into Soul MD, the same prompt produces a different answer 6:33.
  • The answer can be shorter, sharper, and in the requested tone 6:40.
  • The file only needs to be written once, and every session inherits it automatically 6:51.

Tools and skills

  • A tool is one single action, such as search the web, read a file, or run a command 7:09.
  • A skill is the entire playbook: written instructions for combining multiple tools in the right order to finish a real job 7:19.
  • Hermes ships with dozens of built-in skills 7:26.

Dozens already built in#

The agent can write its own skills. The speaker opens an older agent's skills folder and points out that the files were not written by a person; the agent built them from jobs it was given over the last few weeks 7:31–7:39.

Opening one skill shows instructions for how to do a task again. The idea is that the agent solved a hard problem once, then wrote itself a manual so it does not have to figure the task out from scratch every time 7:45–7:55.

Alongside skills, there is a second kind of memory about the user. In a brand-new chat with no history carried over, the agent can still recall specific details, preferences, ongoing projects, and formatting preferences from sessions weeks earlier 8:28–8:47.

Two files are described as running behind the scenes:

Hermes also keeps a full searchable archive of every conversation, so it can dig up information even when it is not in those files 9:18–9:29.

WhatsApp set up and then just#

After starting the WhatsApp setup, scan the QR code with your phone 10:00. The codes expire in about 20 seconds, so if you miss the window, run the command again to get a fresh one 10:02. Once paired, Hermes saves the session, so you do not need to re-scan every time the server boots 10:12.

After pairing, messaging the specific number from your phone reaches the same agent, with the same memory and behavior, only accessed through WhatsApp 10:20.

Two settings are highlighted as commonly misconfigured:

  • Set the allow list after pairing 10:56.
  • Use your own phone number, the number you are messaging from, not the bot's number 11:03.
  • The format matters: include the country code, with no plus sign, no spaces, and no dashes 11:27.
  • Set unauthorized DM behavior to ignore, so strangers do not receive a pairing code instead of silence 11:32.
  • Change the terminal backend from direct server execution to Docker 11:42.
  • By default, commands run directly on the actual server, which can be risky if a bad or destructive command is executed 11:42.
  • Setting the terminal backend to Docker sandboxes commands into a container that can be wiped and rebuilt 11:57.

Fix both settings before connecting anything else 12:07.

After WhatsApp setup, the next step is building a briefing from scratch on the newly deployed agent 12:14. Scheduled tasks run automatically on a schedule without being asked, such as every morning 12:25.
